# Lingopede Companion Releases

Public download host for the Lingopede Companion installers.

## Latest release

[Lingopede Desktop Companion v1.0.0](https://github.com/AhmadAzeez999/lingopede-releases/releases/tag/v1.0.0)

## Why a separate repo?

The Lingopede source code lives in a private repository. This public repo hosts installer binaries with stable HTTPS URLs so they can be downloaded by end users and validated by app store submission systems.
